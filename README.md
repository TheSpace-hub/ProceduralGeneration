# Процедурная генерация

Мини-игра, разработанная каналом [BrilliantSolutions](https://www.youtube.com/@BrilliantSolutionsChess)

## Создание игры

### Создание образа

Пустой мир для генерации карты

> Команда для создания образа: `/bsg create идентификатор-образа`

## Список всех команд

| Команда                              | Описание        |
|--------------------------------------|-----------------|
| /bsg create _идентификатор-образа_   | Создание образа |
| /bsg join _идентификатор-контейнера_ | Перейти в мир   |
