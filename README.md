# Процедурная генерация

Мини-игра, разработанная каналом [BrilliantSolutions](https://www.youtube.com/@BrilliantSolutionsChess)

## Создание игры

### Создание образа

В образе хранятся настройки для будущей игры. Когда игра создаётся, она собирается на основе образа, получая все
необходимые для генерации данные из настроек образа.

Чтобы создать образ, введите `/bsg create image идентификатор-образа`.

Вместо **идентификатор-образа** написать имя, которе характеризует ваш образ _(например, если ваша карта стеклянная, то
хорошим именем будет __solo-glass__)_

После выполнения команды, вы будете перемещены в пустой мир, в котором будет размещён один блок. На этом блоке будут
появляться игроки перед началом игры.

> Команда для создания образа: `/bsg create image идентификатор-образа`

---

### Настройка образа

Сейчас вы можете начать строить место, где будут появляться игроки. Если игрок будет находиться ниже блока спауна, то он
будет телепортирован в начало. Будьте внимательны при постройке.

Чтобы изменить блок, на котором появляются игроки, возьмите руку другой блок и сломайте старый блок. Новый заменит
старый.

Для настройки параметров игры зайдите в файл `config.yml`, далее найдите ваш образ по идентификатору в разделе
`game-settings` и измените значения нужные вам.

Также можно ввести команду `/bsg configure image идентификатор-образа`, чтобы настроить образ в GUI интерфейсе.

> Для настройки образа, введите команду `/bsg configure image идентификатор-образа`

---

### Создание игры

Контейнер с игрой создаётся на основе образа, который нужно создать и настроить прежде, чем создавать контейнер. У
каждого контейнера есть уникальный идентификатор. Вы можете узнать идентификаторы всех контейнеров введя команду
`/bsg container list`.
После создания экземпляра игры, к ней можно подключится, введя команду `/bsg join идентификатор-игры` или через GUI
интерфейс, который открывается командой `/bsg join-gui`

> Чтобы создать экземпляр игры, введите `/bsg create container идентификатор-образа имя-мира`
